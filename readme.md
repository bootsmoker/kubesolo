# KubeSolo

> 单节点 Kubernetes 发行版

## Download

Download offline installer

```bash
curl -fsSL https://raw.githubusercontent.com/bootsmoker/kubesolo/HEAD/download.sh | bash
```

Update setup script

```bash
curl -fsSL https://raw.githubusercontent.com/bootsmoker/kubesolo/HEAD/setup.sh | bash
```

## Install

Install or reinstall kubesoloctl

```bash
curl -fsSL https://raw.githubusercontent.com/bootsmoker/kubesolo/HEAD/install-kubesoloctl.sh | bash
```

Install or reinstall kubectl

```bash
curl -fsSL https://raw.githubusercontent.com/bootsmoker/kubesolo/HEAD/install-kubectl.sh | bash
```

## Uninstall

Uninstall kubectl

```bash
curl -fsSL https://raw.githubusercontent.com/bootsmoker/kubesolo/HEAD/uninstall-kubectl.sh | bash
```
